HEX PATH

Connect the neon power lines from start to finish.

Tap tiles to rotate them. The path glows pink when connected to the energy source.

HOW TO PLAY

1. Start at the Green Hex (Source).
2. Tap hexes to rotate them 60 degrees.
3. Form a path to the Blue Hex (Target).
4. When the target glows, you win the level!
